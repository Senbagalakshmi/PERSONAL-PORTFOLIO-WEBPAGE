It showcases the developer’s background, skills, projects, and resume in a clean and professional manner. The site features a smooth navigation system, multiple content sections, and is optimized for both desktop and mobile devices.
Technical tools are:
1.Frontend:

HTML5, CSS3

Smooth scroll navigation and basic animations

2.Backend:

Python

Flask (for rendering HTML templates and serving static files)

3.Tools:

Visual Studio Code

Git and GitHub for version control
